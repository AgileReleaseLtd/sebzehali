# s-015: Antalya bulletins published as scans

- Status: open
- Priority: P2
- Added: 2026-10-12

## What

When Antalya's PDF has no text layer, read it with text recognition (for example tesseract), and report an unreadable bulletin as "unreadable", not "no bulletin".

## Why

The bulletin for 2026-10-10 is a scanned image: `pdftotext` returns nothing, so the day was skipped silently. The weekday PDFs are made with "Microsoft: Print To PDF" and read fine.

## Done when

The 2026-10-10 bulletin is stored with its prices, and a test covers a scanned PDF.

## Notes

- Text recognition on price tables needs checking against the PDF by eye before trusting it.
