# s-014: GitHub's schedule is unreliable

- Status: open
- Priority: P1
- Added: 2026-10-12

## What

Trigger the workflow from outside GitHub (an external cron calling `workflow_dispatch`), or accept the gaps and say so on the site.

## Why

The workflow is scheduled four times a day. GitHub fired two of the four on 2026-10-11 (one of them over four hours late) and one of the four on 2026-10-12. GitHub documents scheduled runs as best-effort.

## Done when

Four runs a day happen within a few minutes of their slot.

## Notes

- An external trigger needs a token with permission to start workflows, stored with the external service.
